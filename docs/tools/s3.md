# S3

Every tool here accepts an optional `region` — it's only a starting guess, not a requirement. A wrong or omitted guess
is caught automatically via S3's region-redirect response and retried against the bucket's real region, so passing it
just saves one round trip when you already know it.

## `aws_s3_list_buckets`

Lists every S3 bucket visible to a connected profile, with name, region, and creation date. Call this first to discover
which buckets exist — and which region each lives in — before searching or downloading from one.

| Param     | Type   | Required | Description                                                            |
| --------- | ------ | -------- | ---------------------------------------------------------------------- |
| `profile` | string | no       | Profile name. Defaults to `"default"`.                                 |
| `region`  | string | no       | Starting-guess region. Defaults to `AWS_REGION` env, else `us-east-1`. |

**Example call:**

```json
{}
```

**Example response:**

```json
{
  "buckets": [
    {
      "name": "my-app-uploads",
      "region": "eu-central-1",
      "creationDate": "2024-03-11T09:12:00.000Z"
    },
    {
      "name": "my-app-logs",
      "region": "us-east-1",
      "creationDate": "2023-11-02T14:03:20.000Z"
    }
  ]
}
```

## `aws_s3_search_objects`

Lists/searches objects in one bucket. Returns key, size, last-modified, and etag for each match — never object contents
(use `aws_s3_get_download_url` for that). Narrow with `prefix` (fast, server-side) and/or `query`
(case-insensitive substring match against the key, applied client-side after listing).

| Param        | Type   | Required | Description                                              |
| ------------ | ------ | -------- | -------------------------------------------------------- |
| `bucket`     | string | yes      | Bucket name.                                             |
| `prefix`     | string | no       | Only include keys starting with this prefix.             |
| `query`      | string | no       | Case-insensitive substring to match against object keys. |
| `maxResults` | number | no       | Max matching objects. Default 200, max 1000.             |
| `profile`    | string | no       | Profile name. Defaults to `"default"`.                   |
| `region`     | string | no       | Starting-guess region.                                   |

**Example call:**

```json
{
  "bucket": "my-app-uploads",
  "prefix": "invoices/2026/",
  "query": "acme"
}
```

**Example response:**

```json
{
  "bucket": "my-app-uploads",
  "objects": [
    {
      "key": "invoices/2026/acme-corp-0142.pdf",
      "size": 88213,
      "lastModified": "2026-02-14T10:00:00.000Z",
      "etag": "\"5d41402abc4b2a76b9719d911017c592\""
    }
  ]
}
```

## `aws_s3_get_download_url`

Returns a time-limited, read-only presigned URL to download one S3 object directly — never the object bytes or
credentials themselves. Fails clearly if the object doesn't exist. Use `aws_s3_search_objects` first to find the exact
key.

| Param              | Type   | Required | Description                                   |
| ------------------ | ------ | -------- | --------------------------------------------- |
| `bucket`           | string | yes      | Bucket name.                                  |
| `key`              | string | yes      | Exact object key.                             |
| `expiresInSeconds` | number | no       | URL validity. Default 300, max 3600 (1 hour). |
| `profile`          | string | no       | Profile name. Defaults to `"default"`.        |
| `region`           | string | no       | Starting-guess region.                        |

**Example call:**

```json
{
  "bucket": "my-app-uploads",
  "key": "invoices/2026/acme-corp-0142.pdf",
  "expiresInSeconds": 600
}
```

**Example response:**

```json
{
  "bucket": "my-app-uploads",
  "key": "invoices/2026/acme-corp-0142.pdf",
  "url": "https://my-app-uploads.s3.eu-central-1.amazonaws.com/invoices/2026/acme-corp-0142.pdf?X-Amz-Algorithm=..."
}
```
